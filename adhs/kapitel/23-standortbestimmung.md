# Standortbestimmung

Bevor du anfängst, etwas zu ändern, brauchst du zwei Dinge: einen ehrlichen
Blick auf den Ist-Zustand und eine Entscheidung, wo du zuerst ansetzt.

Dieses Kapitel ist Arbeit, keine Lektüre. Nimm dir eine halbe Stunde, Papier
und einen Stift. Nicht das Handy — dort verschwindet es.

> **Was das hier nicht ist:** kein Test und keine Diagnose. Keine der
> folgenden Fragen sagt dir, ob du ADHS hast. Sie sagen dir, wo dein Leben
> gerade Kraft verliert.

## Schritt 1: Die Bestandsaufnahme

Geh die folgenden acht Bereiche durch. Gib jedem eine Zahl von 0 bis 10 — 0
heißt „das ist völlig außer Kontrolle“, 10 heißt „läuft rund“.

Antworte auf den Zustand der letzten vier Wochen, nicht auf deinen besten
Monat und nicht auf deinen schlechtesten.

| Bereich | Leitfrage | 0–10 |
|---|---|---|
| Schlaf | Gehe ich zu einer Zeit ins Bett, die zu meinem Morgen passt? | |
| Wohnung | Kann ich mich in meiner Wohnung aufhalten, ohne dass sie mich bedrückt? | |
| Papierkram | Ist meine Post geöffnet und meine Ablage aktuell? | |
| Geld | Weiß ich, was auf meinem Konto ist, und stimmt es? | |
| Arbeit | Halte ich meine Zusagen und Fristen? | |
| Beziehungen | Melde ich mich zurück bei Menschen, die mir wichtig sind? | |
| Körper | Bewege ich mich, esse ich regelmäßig? | |
| Kopf | Wie oft komme ich zur Ruhe? | |

Zähl nichts zusammen. Die Summe sagt nichts. Interessant sind die zwei
niedrigsten Werte.

## Schritt 2: Die teuersten Momente

Jetzt der wichtigere Teil. Schreib **drei konkrete Situationen** aus den
letzten vier Wochen auf, in denen dich etwas real etwas gekostet hat: Geld,
Zeit, Ansehen, Vertrauen, Nerven.

Konkret heißt: mit Datum und Betrag, nicht als Gefühl.

Nicht: *„Ich bin so unorganisiert.“* Sondern: *„12. März: Zahnarzttermin
verpasst, 40 Euro Ausfallgebühr.“* *„Woche vom 18.: Handyvertrag nicht
gekündigt, läuft ein Jahr weiter, 480 Euro.“* *„23. März: Rückruf bei Mama
vergessen, jetzt ist sie gekränkt und ich weiche aus.“*

Diese Liste ist unangenehm. Sie ist auch das Wertvollste in diesem Kapitel,
denn sie verwandelt ein diffuses Gefühl von Versagen in eine überschaubare
Zahl konkreter Vorfälle. Drei Vorfälle sind bearbeitbar. „Ich bin ein Chaot“
ist es nicht.

## Schritt 3: Die Zuordnung

Ordne jeden der drei Vorfälle einem der vier Grundmuster aus Kapitel 4 zu.

| Vorfall | Muster | Kapitel |
|---|---|---|
| | Zeitblindheit / Reize / Startsperre / Gefühle | |
| | | |
| | | |

Meistens landen zwei oder drei Vorfälle beim selben Muster. Das ist deine
Baustelle.

## Schritt 4: Der Anfangspunkt

Jetzt die Entscheidung — und hier machen fast alle denselben Fehler.

Der Fehler ist, alles gleichzeitig anzugehen. Das Buch ist voller Werkzeuge,
sie klingen alle einleuchtend, und die Begeisterung am Anfang ist echt. In
drei Wochen ist nichts davon übrig, und der alte Satz aus Kapitel 5 hat
frisches Material.

Also:

> **Eine Sache. Vier Wochen. Dann die nächste.**

Wähle nach dieser Reihenfolge:

**Erstens: Steht etwas Akutes an?** Eine unbezahlte Mahnung, eine ablaufende
Frist, eine drohende Kündigung. Dann ist das der Anfang — nicht das System,
sondern der Brand. Kapitel 18 beschreibt, wie du an einen Papierstapel
herangehst, vor dem du dich fürchtest.

**Zweitens: Ist der Schlaf im Keller?** Wenn du unter sechs Stunden liegst
oder regelmäßig um drei Uhr ins Bett gehst, fang dort an. Alles andere in
diesem Buch wirkt schlechter oder gar nicht, solange der Schlaf nicht steht.
Kapitel 9.

**Drittens: Sonst nimm das Muster mit den meisten Vorfällen** aus Schritt 3
und geh in das zugehörige Kapitel.

Trag deine Entscheidung hier ein, mit Datum:

> Ich fange an mit: ________________________________
>
> Am: ____________   Ich schaue wieder hin am: ____________ (vier Wochen später)

Das Datum ist kein Zierrat. Ohne festen Zeitpunkt zum Nachschauen verschwindet
das Vorhaben genauso wie alles andere.

## Schritt 5: Die Ausgangsmessung

Ein letzter Handgriff, der sich in drei Monaten auszahlt. Notiere für deine
gewählte Baustelle **eine einzige Zahl**, die du in vier Wochen wieder messen
kannst:

- Schlaf: Uhrzeit, zu der du diese Woche im Schnitt ins Bett gegangen bist
- Papierkram: Anzahl ungeöffneter Briefe, die gerade herumliegen
- Termine: Anzahl verpasster oder verspäteter Termine im letzten Monat
- Wohnung: Anzahl freier Ablageflächen, auf denen nichts steht

Diese Zahl ist wichtiger, als sie aussieht. Fortschritt bei ADHS ist selten
spürbar, weil der Kopf den neuen Zustand sofort für normal hält und die
Erinnerung an den alten schlecht speichert. Ohne Ausgangswert wirst du in zwei
Monaten glauben, es habe sich nichts geändert.

> Kurz gefasst:
>
> Drei konkrete Vorfälle, ein Muster, eine Baustelle, eine Zahl, ein Datum
> zum Nachschauen. Mehr braucht der Anfang nicht — und weniger trägt nicht.
