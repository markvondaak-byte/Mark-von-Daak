# Vorlagen

Fünf Vorlagen zum Abschreiben oder Kopieren. Wer sie abfotografiert und
ausdruckt, hat sie in der Küche griffbereit.

## 1 · Das Tagebuch

Eine Zeile je Mahlzeit, eine Seite je Tag.

| Uhrzeit | Was | Wie | Stuhlgang | Beschwerden | Sonstiges |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

**Wie** = in Ruhe · nebenbei · im Stehen · gehetzt
**Stuhlgang** = Uhrzeit und Bristol-Typ 1 bis 7
**Beschwerden** = was, wann, Stärke 0 bis 10
**Sonstiges** = Schlafdauer, Bewegung, Anspannung, Medikamente, Alkohol
